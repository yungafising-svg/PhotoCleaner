# Чистка фото — iPhone-приложение

Находит похожие кадры и дубликаты (оставляет лучший), размытые, тёмные и пересвеченные фото,
неудачные лица и скриншоты. Для неудачных живых фото подбирает лучший титульный кадр.
Всё считается на телефоне, интернет не используется. Нужна iOS 17+.

## Что внутри
- Защита: избранное, фото из альбомов и отредактированные не трогаются; список «не трогать».
- Корзина приложения: всё отмеченное сначала собирается для финальной проверки.
- Память: решения и результаты анализа сохраняются, повторный скан — только новые фото.
- «Это не дубли», ручной выбор лучшего, сравнение на весь экран с зумом.
- Свайп по месяцам с отменой.

## Сборка
Каждый push в `main` собирает `PhotoCleaner.ipa` в GitHub Actions (вкладка Actions → Artifacts).

## Установка (Windows + Sideloadly)
1. iTunes и iCloud с сайта Apple (не из Microsoft Store), затем Sideloadly.
2. iPhone по кабелю → «Доверять». Перетащить `.ipa` в Sideloadly, ввести Apple ID, Start.
3. На iPhone: Режим разработчика → вкл; Основные → VPN и управление устройством → доверять.
4. С бесплатным Apple ID — переподписывать раз в 7 дней (в Sideloadly есть авто-обновление).
